# MgameIO Control Center

Приложение для Windows 10/11. Сборка EXE публикуется в корне репозитория.

После публикации: [скачать MgameIO_Control_Center.exe](./MgameIO_Control_Center.exe).

Исходный архив приложения расположен в `mgameio/source.tar.gz.b64`; workflow собирает Windows EXE из Go-исходников без установки сторонних зависимостей. Интерфейс запускается в установленном браузере Windows.
